# Complete React Project with CRA (Deprecated)

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app) after studying a complete [React Course](https://www.codebreakthrough.com/products/free-react-course).

## Features

**Current**
- Rendering a list of employees from a static data
- Add new employee and edit employee details
- Render a list of customers fetched from an external API
- Add a new customer and edit customer details
- Dictionary search box that returns the definition of user-input word from an external API

**Future**
- Complete CRUD operations for both employees and customers
- Handle loading and error states while fetching data from backend API
- Integrate MSW for mocking backend APIs
- Implement unit and end-to-end testing

## Tech Stack
- ReactJS v18 and related libraries
- CRA CLI (Deprecated)
- Backend API (Django REST Framework managed on different repository)
- Headless UI with Tailwind CSS
