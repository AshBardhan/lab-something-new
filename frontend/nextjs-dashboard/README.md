## Next.js App Router - Dashboard

This is the fullstack web application after completing [Next.js App Router Course](https://nextjs.org/learn/dashboard-app) and deployed on [Vercel](https://nextjs-dashboard-mydemo.vercel.app).

## Features

**Current**
- Login Page with Authentication
- Dashboard page showcasing invoice and customer summary
- Invoice page showing list of paid and unpaid invoices
- Complete CRUD operations for invoices

**Future**
- Add filtering and dynamic page limiting to invoice page
- Customer page showing list of all customers
- Complete CRUD operations for customers
- Setup a local PostgreSQL database
- Integrate MSW for mocking backend APIs
- Implement unit and end-to-end testing

## Tech Stack
- NextJS and related libraries
- ReactJS and related libraries
- TypeScript
- PostgreSQL (deployed in Vercel)
- Zod
- Tailwind CSS

## Setup & Run
1. Install dependencies with `npm install`
2. Start development server with `npm run dev`
3. Open http://localhost:3000 in your browser and login with credentials provided below:
```
Username: user@nextmail.com
Password: 123456
```
4. To build production version, use `npm run build` command.
